# Futsal App

This repository is now organized into clear frontend, backend, legacy algorithm, and documentation areas.

- `frontend/` contains the Create React App client.
- `backend/auth-service/` contains the auth/user/avatar API.
- `backend/futsal-service/` contains the futsal search and booking API.
- `data-structures/` keeps older standalone DSA experiments separate from runtime code.
- `docs/legacy-html/` stores old static HTML experiments that are no longer part of the React app.

See `docs/PROJECT_STRUCTURE.md` for the full layout and run commands.
